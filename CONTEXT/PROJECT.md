# Project

## What this is

Four chatbots, built from scratch to production standard, as a way of
learning software engineering, product thinking, and testing.

Owner: Surabhi
Started: September 2026

## The four products

1. Triage - reads a customer support message, decides which team it goes to and how urgent it is.
2. PolicyDesk - answers refund questions by reading company help documents.
3. OpsAgent - can actually do things, like look up an order and issue a refund.
4. Coach - holds a real multi-turn conversation with a consistent personality.

They are built in that order on purpose. Each one adds exactly one new hard problem.

## How the work is done

Claude teaches, Surabhi does the work. Nothing gets created without
being asked for first. Every technical term gets explained in plain
English and recorded in GLOSSARY.md.

## Source material

The evaluation approach comes from the Chatbot Eval Playbook, which covers how to measure a chatbot. The engineering, product, and testing side is what this project adds.
